# Notes for agents working on this repo

## GitHub issues and PRs

- Don't change or delete existing text in an issue or PR description, even text posted from the account you use. You may add to it, for example a dated update section, and tick task checkboxes.
- To reframe an issue or PR, post the new scope as a comment, then add a short note at the top of the description that links to that comment. You may change the title to match the new scope.
